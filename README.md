### The main course

**[42Marketplace](https://github.com/Coder42Y/42Marketplace)** — One place for the
notes, skills, agent patterns and MCP servers I keep re-deriving. Written down so
I stop solving the same problem twice.

**[full-stack-ai-agent-template](https://github.com/Coder42Y/full-stack-ai-agent-template)**
— An interactive generator that turns 199 config choices into a production-grade
FastAPI + Next.js app: agents, RAG, multi-tenancy, billing, admin. Ships with
WorkMate, a real internal-assistant app it generated, so you can see the output
before you trust the machine.

**[mr-pr-code-review-bot](https://github.com/Coder42Y/mr-pr-code-review-bot)** —
Self-hosted AI review for GitLab merge requests. Spec-driven findings, each one
verified before it is posted, and a human still holds the merge button. Built
because a review bot that cries wolf gets muted in a week.

**[OmniFlow](https://github.com/Coder42Y/OmniFlow)** — An autonomous multi-agent
creative studio for media production. The ambitious one. Ask me again in a few
months.
